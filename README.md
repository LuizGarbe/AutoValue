AutoValue
Projeto acadêmico em HTML, CSS e JavaScript para estimar a desvalorização de um veículo.

Como executar
Baixe ou extraia os arquivos.
Abra o arquivo index.html no navegador.
Informe modelo, ano, quilometragem e valor atual.
Clique em Calcular estimativa.
Regra utilizada
O projeto usa uma regra propositalmente simples:

5% de desvalorização ao ano;
+1 ponto percentual se a quilometragem passar de 100.000 km;
+2 pontos percentuais se passar de 200.000 km.
A estimativa não representa uma cotação oficial de mercado ou FIPE.

Arquivos
index.html — estrutura da página
style.css — visual, Grid e responsividade
script.js — cálculo
carro.svg — imagem usada no HTML
